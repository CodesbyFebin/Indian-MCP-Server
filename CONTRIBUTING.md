# Contributing

Thanks for contributing to MCPServer OS.

## Development

1. Fork or clone the repository.
2. Enable Corepack and install dependencies with `pnpm install`.
3. Run `pnpm typecheck` and `pnpm build` before opening a PR.
4. Keep changes focused and update documentation when behavior changes.

## Pull requests

- Use a clear conventional-style commit message.
- Include tests or verification steps for behavior changes.
- Do not commit secrets, local `.env` files, or production credentials.
- Keep security-sensitive changes explicit and reviewable.
